# Portfolio website

A responsive portfolio for Sajjat Hossain Abir, matching the GitHub profile's dark navy, cyan, and lime design.

## Run

Open `index.html` in a modern browser. No installation or build is required.

Alternatively, from this folder run `python -m http.server 8000` and visit `http://localhost:8000`.

## Features

- Responsive navigation and project layout.
- Filter projects by website, software, or security.
- Light/dark theme switch with a saved preference when browser storage is available.
- Keyboard-accessible controls and email/GitHub contact links.

Project links point to the public source and setup guides. This repository includes website source; a public live website URL has not been configured.
